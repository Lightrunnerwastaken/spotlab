> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Räume mit Podesten, Rampen und Treppen laden, speichern und in beiden Sims befahren: der Körper folgt dem Boden (z, Nick), Klippen und Körperband gelten in Kollision und Gitter, die Treppenregel verweigert falsch herum, der Treppenmodus steht in der Konfiguration, die Puppe (Fassung 4) baut Stufen und neigt sich.

**Architecture:** Ein Element `Boden` im Raumformat v3; `welt/hoehe.py` (Standardbibliothek) ist die einzige Höhenauskunft (`boden_bei`) und die einzige Kastenzerlegung (`kaesten_fuer`); Kollision, Gitter, 2D-Sim, MuJoCo-Welt und Puppe formulieren die Regel „Hindernis = Höhensprung über `MAX_STUFE_M`".

```python
def boden_bei(raum, x, y, z_nahe=0.0, ohne=None):
    beste = (0.0, None)
    for boden in raum.boeden:
        if boden is ohne:
            continue
        lx, ly = boden.lokal(x, y)
        if abs(lx) <= boden.breite / 2 and abs(ly) <= boden.tiefe / 2:
            z = boden.hoehe_lokal(lx)
            if (abs(z - z_nahe), -z) < (abs(beste[0] - z_nahe), -beste[0]):
                beste = (z, boden)
    return beste
```

`neigung_bei`: Steigung `anstieg/breite` entlang der lokalen x-Achse, gedreht in die Welt. `nick_grad = degrees(atan(dzdx*cos(yaw) + dzdy*sin(yaw)))`. `klippen`: je Boden, je Kante Stücke à `schritt`; innen `hoehe_lokal` am Stückmittelpunkt (leicht nach innen versetzt, 1 mm), aussen `boden_bei(..., z_nahe=innen, ohne=boden)` 1 mm nach aussen; `alles=True` markiert jede Kante von Rampen und Treppen (Treppenmodus aus). Zusammenhängende Stücke einer Kante zu einer Strecke verschmelzen. `treppe_vor`: Fusskante = Kante bei `lx = -breite/2`, Kopfkante bei `+breite/2`; Abstand vom Roboter zum Kantenmittelpunkt-Segment; Roboter „am Fuss", wenn er näher an der Fusskante ist; Peilung wie `richtung()` (aber ohne Import aus backends — eigene `atan2`); Achse bergauf = Weltvektor der lokalen +x-Achse; `achsenwinkel = |winkel(fahrtrichtung) − winkel(achse)|` auf 0..180; Sicht mit `sicht_frei`; nur wenn `abstand <= TREPPE_SICHT_M` und der Kantenpunkt vor dem Roboter liegt (Skalarprodukt mit Blick > 0) ODER der Roboter rückwärts auf ihn zufährt — die Funktion liefert die Lage, die Regel entscheidet. `kaesten_fuer`: Stufe i (0-basiert): Tiefe `breite/stufen`, Mitte lokal `lx = -breite/2 + (i+0.5)*tiefe`, Oberkante `z + (i+1)*anstieg/stufen`, Kasten von `boden_z` bis Oberkante; Rampe: geneigter Kasten mit `hx = hyp/2` (Hypotenuse), `hz = RAMPE_DICKE_M/2`, Mitte bei `(z + z_oben)/2 - RAMPE_DICKE_M/2 · cos(neigung)`, `pitch_grad = neigung_grad`, plus Füllkasten von `boden_z` bis `min(z, z_oben)` (fällt weg, wenn ≤ boden_z); Podest: Kasten `boden_z..z` (weg, wenn `z <= boden_z`). Namen `stufe_{name}_{i}`, `rampe_{name}`, `boden_{name}` — die Puppe ignoriert Berührungen mit `boden_`, `stufe_`, `rampe_`.
